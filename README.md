## Accompagnateur vocal trilingue
Bouton 🎧 (en bas à droite) : active une voix qui lit chaque question, explique chaque réponse juste ou fausse, lit les fiches, le mémento, les bilans et décrit les éléments du site.

**Langue de l'accompagnateur** (menu du panneau) : Français, العربية (arabe standard) ou الدارجة المغربية (darija). En arabe et en darija :
- les phrases d'accompagnement, les introductions, les bilans et les explications des 227 questions des 3 QCM (Pédagogie, Entraînement, Mémento) sont dites dans la langue choisie ;
- les questions, les propositions et les termes techniques restent en français (langue de l'épreuve) et sont lus par une voix française ;
- les cartes et corrections des anciens onglets (QCM Auteurs, Flashcards) restent en français, seules les phrases d'accompagnement sont traduites.

Voix arabe : le site utilise les voix installées sur l'appareil (ar-MA en priorité pour la darija, sinon ar-SA / ar-EG). Edge (voix « Natural » en ligne) donne le meilleur rendu ; sur Chrome Windows, Android et iPhone, installer une voix arabe dans les réglages de synthèse vocale. Sans voix arabe, un avertissement s'affiche dans le panneau.

Les traductions arabe/darija sont générées par IA : à relire (la darija en particulier).

Réglages : voix, vitesse, ce qui est lu. Raccourcis dans les QCM : R répéter, Échap arrêter.

Les réponses des QCM sont établies par analyse pédagogique : à vérifier avec le cours.
