# QCM Pédagogie · Promotion interne OFPPT

Page web interactive (un seul fichier `index.html`, sans dépendance) pour maîtriser les QCM de pédagogie des concours de promotion interne OFPPT (sujets 2019-2020, formateurs).

- 67 questions uniques, regroupées en 8 thèmes
- **Entraînement** : 10 questions, correction et explication immédiates
- **Examen blanc** : 30 questions, 30 min, bilan avec corrections
- **Mes erreurs** : rejouer uniquement ce qui a échoué
- **Fiches** : révision question → réponse
- Progression enregistrée dans le navigateur (localStorage)
- Options mélangées à chaque passage, clavier (1-4 / a-d, Entrée), mode sombre automatique

## Utilisation

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages (Settings → Pages → branche `main`, dossier `/root`).

## Avertissement

Les réponses sont établies par analyse pédagogique à partir de photos de sujets, pas à partir d'un corrigé officiel. Les questions signalées « à vérifier » doivent être contrôlées avec le cours.
